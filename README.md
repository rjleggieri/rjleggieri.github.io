# Robert Leggieri | Applied AI & NLP Projects

Personal portfolio for [rjleggieri.github.io](https://rjleggieri.github.io), featuring selected public work and public-safe summaries of graduate projects completed in the M.S. Artificial Intelligence program at The University of Texas at Austin.

## Local development

```bash
pnpm install
pnpm run dev
```

## Production build

```bash
pnpm run build
```

The site is a static Vite build. GitHub Pages can publish the generated `dist` directory through a Pages workflow or the project can be deployed directly from source with a compatible static hosting provider.

The homepage contains the project context and implementation details. The
text-prosody link opens its report directly; older project URLs redirect to the
report or the corresponding homepage feature. Remaining pages in `projects/`
are registered as Vite build inputs. Core content and links remain usable without JavaScript.

The social-sharing image is `public/assets/portfolio-social.jpg`. Its editable
HTML source is `scripts/social-card.html`; render it at 1200 × 630 pixels when
updating the image so the shared preview stays consistent with the homepage.

The BQE workload-planner illustration is generated by
`python scripts/generate_workload_preview.py`. Its people, projects, assignments,
and figures are invented. The generator never reads the private GLW workbook;
do not add that workbook or company records to this repository.

## Documents

The editable document sources are `scripts/generate_resume.py` and
`scripts/generate_nli_report.py`. Install the build dependencies with
`python -m pip install -r scripts/requirements-documents.txt`, then run:

```bash
python scripts/generate_resume.py
python scripts/generate_nli_report.py
python scripts/validate_documents.py
```

Both generators update the copies under `docs/`, `public/docs/`, and `output/pdf/`.
The NLI paper presents the study as a standalone manuscript, with methods,
results, discussion, limitations, and verified references. The document validator
checks the experimental values and figure against the archived course artifact
under `docs/archive/` and checks consistency of all published PDF copies.

The text-prosody report is generated by `scripts/generate_prosody_report.py`,
using the aggregate and conceptual figures in `paper/prosody-figures/`. It writes
`Text-Prosody-Misalignment.pdf` to `output/pdf/`, `docs/`, and `public/docs/`.
It documents the implemented feature pipeline, retained study results, and
confirmed audio-label mapping defect; generation never fits a model.
