03 / Multimodal research · UT Austin · Public Python framework

Text–prosody research,
from utterance to evaluation.

I designed the Alignment Discrepancy Score (ADS) and built an end-to-end pipeline covering 32,401 utterances across 189 DAIC-WOZ interviews: aligned audio and transcripts, pretrained affect-model outputs, five session-level features, and PHQ-8 prediction.

The saved five-fold out-of-fold predictions reached AUC 0.609 and average precision 0.410, above the 0.302 prevalence baseline. Sentiment-based ADS was the stronger implemented variant.

What the analysis established. The implemented features showed a modest association with PHQ-8 group. Text-only prediction was stronger (AUC 0.706). An audio-label adapter defect collapsed the speech-affect projection onto sadness probability, so these results describe the implemented pipeline; they do not validate emotional incongruence as a measure.

Engineering follow-through

I extended the research into text-prosody-evidence: reusable grouping, nested evaluation, calibration, reliability, and provenance software. A separate public EmoBank text-component benchmark improved valence RMSE from 0.4276 to 0.3908 under document-grouped evaluation.

Project history,

I built a read-only connector that turns authorized BQE CORE project, time, expense, and billing records into a validated local warehouse and traceable planning outputs.

See where the work goes

Surface items for review

Summarize estimated unbilled time, invoicing, payments, and outstanding balances in a management brief.

Give AI tools a traceable input

Export JSON and Markdown with source metadata, data coverage, checkpoints, and validation results.

The engineering behind the output

  • Resumable ingestion: pagination, rate-limit retries, incremental checkpoints, and permission-aware resource handling.
  • Traceable records: raw response evidence, SHA-256 deduplication, normalized upserts, and integrity checks.
  • A controlled write boundary: OAuth PKCE with read-only scope; API write methods are blocked before network access.
