Public reference software · Alpha · Public release July 2026

Reproducible evaluation for text and speech models

A dataset-neutral Python framework for building and auditing evidence around text and speech affect components.

Inspect text-prosody-evidence ↗

Implementation

The framework provides contracts for paired references, grouping across leakage-related records, nested grouped evaluation, calibration sensitivities, reliability interfaces, guarded bootstrap intervals, provenance, and evidence manifests.

Evidence available today

  • Text: bounded component evidence and a reproducible source-document-grouped demonstration using EmoBank.
  • Audio: runtime verification without independent human-reference validity evidence.
  • Cross-modal pipeline: deterministic synthetic verification, rather than scientific validation.

Separate component evidence does not establish validity of a difference between components. The software is nonclinical and does not measure internal state or provide a diagnostic construct.

Relationship to the course study

This is a separate engineering follow-on to the exploratory text/prosody project. It does not reproduce or validate the original ADS findings. Its contribution is the evaluation machinery and explicit evidence boundaries.

What this work demonstrates

Reproducible experiment design, leakage-aware evaluation software, testing, calibration and reliability interfaces, and clear separation of software behavior from empirical claims. The repository documents AI-assisted development and author responsibility.
