Professional project · Gutschick, Little & Weber, P.A.

Auditable business-data integration for planning and reporting

A read-only connector that turns authorized BQE CORE operational and financial records into a normalized, validated warehouse and traceable reporting outputs.

Inspect the public repository ↗

Workflow and implementation

I built the API ingestion, SQLite storage, validation, and planning exports. OAuth Authorization Code with PKCE requests read-only access. The connector handles pagination, retries, deduplication, resource permissions, and incremental checkpoints; raw response evidence and sync history make outputs traceable.

  1. Authorize read-only access
  2. Ingest permitted records
  3. Normalize and validate
  4. Export reporting and planning context

Operating context

The connector feeds an internal reporting and planning workflow that also uses a proprietary workload workbook. The public repository provides synthetic examples and a repeatable mock workflow.

Validation and boundaries

The implementation includes integrity checks and tests for pagination, checkpoints, and partial permissions. BQE remains the system of record; the connector cannot write changes back to it. Financial outputs require reconciliation, and planning outputs support human review. The integration is independent and is not endorsed by BQE Software.

Relevance to research software

The transferable work is connecting constrained data sources, retaining provenance, handling incomplete permissions, and providing inspectable inputs for downstream analysis.
